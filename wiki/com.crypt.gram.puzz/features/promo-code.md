# Promo Code

A dialog in Settings for entering a promo code: a text field, a PASTE CODE button and an APPLY button. No code was applied in this session, so what a code gives is not known [^s2].

## Why it appeared

The Promo Code row is in Settings from the first launch [^s1].

## Where to find it

Home screen > the gear at the top right > Settings > Promo Code, the fifth row, with an icon of asterisks in a box [^s1].

![The Settings popup; Promo Code is the fifth row, with an asterisks-in-a-box icon](../img/20261003-promo-code-entry-c36b2c96.webp) [^s1]
*Settings: the Promo Code row, fifth from the top*

## What it looks like

![The Promo Code dialog at the bottom of the screen over Settings: "Enter your promo code", an empty text field, PASTE CODE and APPLY, a close X at its top right](../img/20261003-promo-code-screen-c02ba4d6.webp) [^s2]
*The Promo Code dialog over Settings: the text field, PASTE CODE (blue), APPLY (green), the close X*

The dialog opens over Settings with the title "Enter your promo code", a text field, a blue PASTE CODE button and a green APPLY button, and a close X at its top right [^s2]. When the phone's keyboard opens for the field, the dialog moves up above it [^s3].

## How it works

- The X closes the dialog back to Settings [^s3].
- PASTE CODE and APPLY were not tried; what a valid code gives is not known.
