# Amaze GO!

[Google Play](https://play.google.com/store/apps/details?id=com.oakever.arrows) · version 1.33.0

Tap arrows that have a free path to make them leave the board; a blocked tap costs one of 3 drops. Hard levels (L5, L8, L10) are boards several screens wide with a free hint. Home carousel with locked Bronze League (L11), Shark Run (L70), Daily Challenge (L20) and Countryside Capers (L16), a daily streak, themes, Zen Mode and a cloud save that restored progress on install.
