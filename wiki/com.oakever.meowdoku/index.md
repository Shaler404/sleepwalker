# Meowdoku: Brain Puzzle Games

[Google Play](https://play.google.com/store/apps/details?id=com.oakever.meowdoku) · version 1.19.1

A Queens-style logic puzzle with cats (one cat per row, column and colour region, cats never touch). Fish per level feed a 24-hour fish leaderboard event, three boosters with rewarded refills, a daily challenge, a daily streak, profile skins and frames, interstitials and banners.
